---
title: Network & secrets
description: Limit what a sandbox can reach, and give it credentials it can use but not read.
---

## Allow only some domains

```typescript
// src/DevBox.ts
import * as Daytona from "@alchemy.run/daytona";
import { Base } from "./Images.ts";

export const DevBox = Daytona.Sandbox("DevBox", {
  snapshot: Base,
  domainAllowList: ["github.com", "registry.npmjs.org"],
});
```

Daytona enforces the list outside the sandbox. Use `networkAllowList` for CIDR ranges and `networkBlockAll` to cut the network entirely. All three change in place.

## Per sandbox at runtime

```typescript
const sandbox = yield* sandboxes.create({
  domainAllowList: "api.openai.com,github.com",
  networkBlockAll: false,
});
yield* sandbox.updateNetworkSettings({ domainAllowList: "github.com" });
```

## A secret the sandbox can't read

```typescript
// src/Secrets.ts
import * as Daytona from "@alchemy.run/daytona";
import * as Alchemy from "alchemy";

export const NpmToken = Daytona.Secret("NpmToken", {
  value: Alchemy.Secret("NPM_TOKEN"),
  hosts: ["registry.npmjs.org"],
});
```

```typescript
// src/DevBox.ts
import * as Daytona from "@alchemy.run/daytona";
import { Base } from "./Images.ts";
import { NpmToken } from "./Secrets.ts";

export const DevBox = Daytona.Sandbox("DevBox", {
  snapshot: Base,
  secrets: { NPM_TOKEN: NpmToken },
});
```

The sandbox sees a placeholder in `$NPM_TOKEN`. Daytona's egress proxy swaps in the real value on requests to `registry.npmjs.org`, and nowhere else. Code in the sandbox, or an agent, can use the token without being able to read it.

## A secret per user

```typescript
const secrets = yield* Daytona.CreateSecret();
const github = yield* secrets.put({ name: `github-${user}`, value: token, hosts: ["api.github.com"] });
const sandbox = yield* sandboxes.create({ secrets: [{ GITHUB_TOKEN: github.name }] });
```

The Worker's key has `manage:secrets`. Destroy deletes the secrets it created.
