Build an API where each user gets a sandbox with their own files. The finished code is in [`examples/cloudflare-modal-sandbox`](https://github.com/alchemy-run/alchemy/tree/main/examples/cloudflare-modal-sandbox).

## Prerequisites

Finish [Modal setup](/modal/setup) and [Cloudflare setup](/cloudflare/setup).

## Create an environment

```diff lang="typescript"
// src/Sandbox.ts
+import * as Modal from "@alchemy.run/modal";
+
+export const Agents = Modal.Environment("Agents", {});
```

Everything the app creates goes in this environment.

## Create an app

```diff lang="typescript"
// src/Sandbox.ts
import * as Modal from "@alchemy.run/modal";
+import * as Effect from "effect/Effect";

export const Agents = Modal.Environment("Agents", {});
+
+export const Coder = Effect.gen(function* () {
+  const agents = yield* Agents;
+  return yield* Modal.App("Coder", { environment: agents });
+});
```

Sandboxes run in an app. Yield `Agents` to put the app in it.

## Build an image

```diff lang="typescript"
// src/Sandbox.ts
export const Coder = Effect.gen(function* () {
  const agents = yield* Agents;
  return yield* Modal.App("Coder", { environment: agents });
});
+
+export const Node = Effect.gen(function* () {
+  const app = yield* Coder;
+  return yield* Modal.Image("Node", {
+    app,
+    image: "node:22-bookworm",
+    commands: ["RUN apt-get update && apt-get install -y git"],
+  });
+});
```

Modal builds it remotely. You don't need Docker.

## Deploy

```typescript
// alchemy.run.ts
import * as Cloudflare from "@alchemy.run/cloudflare";
import * as Modal from "@alchemy.run/modal";
import * as Alchemy from "alchemy";
import * as Effect from "effect/Effect";
import * as Layer from "effect/Layer";
import { Node } from "./src/Sandbox.ts";

export default Alchemy.Stack(
  "CloudflareModalSandboxExample",
  {
    providers: Layer.mergeAll(Cloudflare.providers(), Modal.providers()),
    state: Alchemy.localState(),
  },
  Effect.gen(function* () {
    const node = yield* Node;
    return { image: node.imageId };
  }),
);
```

Run `alchemy deploy`. The output shows the image id (`im-…`).
